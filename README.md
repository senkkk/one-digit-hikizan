# ひきざんのぶどうえん

1から10までの かずどうしを ひく、ほいくえん ねんちょうむけの かんたんな あぷりです。

## あそびかた

1. ぶどうの かずを かぞえます。
2. とった ぶどうを ひいて、のこりを かぞえます。
3. こたえを いれるか、したの かずを えらびます。
4. 10もん せいかいすると、たべものを ひとつ ゲットできます。
5. なんども あそんで、50この たべもの ずかんを うめます。

## ためしかた

そのまま `index.html` を ひらくと あそべます。

ろおかるさあばあで みる ときは、つぎを つかいます。

    python3 -m http.server 8000

そのあと `http://localhost:8000` を ひらきます。
